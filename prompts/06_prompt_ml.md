# Prompt Engineering pour le Machine Learning [bloc 6]

## Objectif

L'objectif de cette partie est de concevoir des prompts destinés à assister les différentes étapes d'un projet de Machine Learning, depuis le prétraitement des données jusqu'à l'interprétation des modèles et des métriques d'évaluation.

## 6.1 — Prétraitement du dataset

Tu es un expert en Machine Learning et en préparation des données.

À partir du dataset des capteurs fourni, propose des stratégies adaptées pour :

- le traitement des valeurs manquantes ;
- la suppression ou le traitement des doublons ;
- la détection et le traitement des valeurs aberrantes ;
- l'encodage des variables catégorielles.

Pour chaque point, indique :

- la méthode proposée ;
- les avantages ;
- les limites ;
- les risques associés.

N'invente aucune information sur le dataset. Base-toi uniquement sur les données fournies.
